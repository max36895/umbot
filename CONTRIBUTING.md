# Contributing to umbot

Спасибо, что хотите помочь в развитии umbot! Ниже краткая инструкция.

## Разработка

1. Склонируйте репозиторий
2. Установите зависимости: `npm install`
3. Запустите тесты: `npm run test` (Jest через ts-jest запускается против исходников `src/` — отдельная сборка не нужна; `npm run build` требуется для `examples/` и CLI-тестов)
4. Проверьте линтер и форматирование: `npm run lint`, `npm run prettier`

> Полные правила для контрибьюторов (архитектурные инварианты, порядок проверки, антипаттерны) —
> в [AGENTS.md](AGENTS.md). Специализированные инструкции по задачам (новая платформа, middleware, тесты,
> релиз) — в `.agents/skills/`.
>
> Claude Code читает скилы только из `.claude/skills`. Связь с `.agents/skills` создаётся автоматически
> при `npm i` (хук `prepare`), в git не коммитится. Пересоздать вручную — `npm run skills:link`.

## Стандарты кодирования

- **Язык комментариев и JSDoc** — русский.
- **Форматирование** — `npm run prettier` (конфиг в `.prettierrc`).
- **Линтинг** — `npm run lint` (ESLint). Ошибки линтинга должны быть исправлены до отправки PR.
- **Тесты** — новая логика должна быть покрыта Jest-тестами. Запуск: `npm run test`.
- **Билд** — `npm run build` должен проходить без ошибок.
- **Безопасность** — никогда не коммитьте токены, пароли или секреты. Используйте `.env`.
- **Документация** — новая функциональность, новая опция или изменение поведения сопровождаются правкой документации (`src/docs/`, при необходимости `README.md`) и JSDoc в том же PR. Карта «что изменил → что обновить» — в [AGENTS.md](AGENTS.md), раздел 6. PR с фичей без документации возвращается на доработку.
- **CHANGELOG** — запись добавляется в секцию релизируемой версии. Секция `[Unreleased]` в проекте не используется; если подходящей секции нет, уточните у мейнтейнера номер версии и срок релиза.

## Pull Requests

- Создавайте ветку от `main` с именем `feature/...` или `fix/...`
- Описывайте изменения в PR
- Убедитесь, что CI проходит и тесты зелёные
- Проверьте, что документация и CHANGELOG обновлены вместе с кодом

## Issues

- Перед созданием проверьте, нет ли дубликата
- Прикладывайте шаги воспроизведения, логи, версию окружения

## Лицензия

Принимая участие, вы соглашаетесь, что ваш код будет распространяться под той же лицензией, что и проект.
