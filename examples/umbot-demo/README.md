# umbot-demo — «Кофейня-бот»

**Один код — 7 платформ.** Это законченный демо-бот на фреймворке [umbot](https://github.com/max36895/umbot): бариста принимает заказы через многошаговую форму, запоминает любимый напиток, считает итоговую сумму и дарит каждый 5-й кофе. Один и тот же код без изменений отвечает и голосовой Алисе, и Telegram, и VK, и ещё четырём платформам.

## Быстрый старт

```bash
git clone https://github.com/max36895/umbot.git
cd umbot/examples/umbot-demo
npm install
npm run dev
```

После запуска говорите с ботом прямо в терминале: «меню», «заказать», «любимый», «помощь». Выход — `exit`.

```text
Ваш запрос: > кофе

Ваш запрос: > любимый

Ответ: > Заказ №2 принят: средний кофе для Иван. Итого: 180 ₽.
```

А теперь то же самое на двух разных платформах — и это один и тот же код. В тестах (`tests/coffee.test.ts`) бот отвечает и структурированным JSON-ом Алисе, и сообщением Telegram:

| Платформа | Что приходит в ответ на «заказать»                    |
| --------- | ----------------------------------------------------- |
| Алиса     | JSON с `response.text`, кнопками и `session_state`    |
| Telegram  | Текст сообщения, доставленный через адаптер платформы |

## Что здесь показано и где это смотреть

| Возможность umbot                             | Где смотреть                                                              |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| Вся логика — цепочка команд (без контроллера) | `src/index.ts` — `createCoffeeBot`                                        |
| Команды (`addCommand`) и слоты                | `src/index.ts` — `welcome`, `help`, `menu`, `favorite`, `order`, fallback |
| Авто-слоты для `welcome`/`help`               | `src/index.ts` — пустой массив слотов, фреймворк подставляет сам          |
| Многошаговая форма (`addForm`)                | `src/index.ts` — форма `order` (напиток → объём → имя) с валидацией       |
| Шаги диалога (`addStep`)                      | `src/index.ts` — шаг `confirm_favorite`                                   |
| Типизированный `userData` без контроллера     | `src/menu.ts` — `CoffeeCtx = BotController<ICoffeeUserData>`              |
| Состояние: история, любимый напиток, итог     | `src/types/ICoffeeUserData.ts`, `src/menu.ts` — `completeOrder`           |
| Продуктовый слой: цены, лояльность            | `src/menu.ts` — `MENU`, `SIZES`, `getPrice`, `LOYALTY_EVERY`              |
| Кнопки (`buttons.addBtn`)                     | `src/index.ts` — `showWelcome`, команды; `src/menu.ts` — `completeOrder`  |
| Карточка-галерея с ценами (`card.addImage`)   | `src/index.ts` — команда `menu`                                           |
| NLU: подтверждение (`YANDEX.CONFIRM`)         | `src/index.ts` — шаг `confirm_favorite`                                   |
| NLU: извлечение числа («закажу два кофе»)     | `src/menu.ts` — `extractCount`                                            |
| Middleware (`rateLimiter`, `requestId`)       | `src/index.ts` — `bot.use(...)`                                           |
| Файловая БД (`FileAdapter`)                   | `src/index.ts`, `src/config/appConfig.ts`                                 |
| Консольный режим (`BotTest`)                  | `src/dev.ts`                                                              |
| Webhook-режим (`Bot.start`)                   | `src/server.ts`                                                           |
| Тесты через `BotTest.simulate`                | `tests/coffee.test.ts` (Алиса + Telegram)                                 |

## Команды бота

| Команда    | Что делает                                                              |
| ---------- | ----------------------------------------------------------------------- |
| «привет»   | Приветствие с кнопками (срабатывает и на первое сообщение)              |
| «меню»     | Карточка-галерея напитков с ценами                                      |
| «заказать» | Форма заказа; если есть любимый напиток — сначала спросит «как обычно?» |
| «любимый»  | Покажет любимый напиток из `userData`                                   |
| «помощь»   | Список команд + напоминание про лояльность                              |
| остальное  | Дружелюбный fallback с подсказкой                                       |

**Продуктовые детали** (все — на `userData` и чистом TypeScript из `src/menu.ts`): у каждого напитка есть базовая цена, у размера — наценка, заказ получает номер и итог, а каждый 5-й заказ проходит бесплатно.

## Запуск и тесты

| Команда         | Что делает                                                      |
| --------------- | --------------------------------------------------------------- |
| `npm run dev`   | Консольный режим: `BotTest` + `bot.test()` — без токенов и сети |
| `npm start`     | Webhook-сервер на `localhost:3000` для реальных платформ        |
| `npm test`      | Jest-тесты через `BotTest.simulate()` (Алиса и Telegram)        |
| `npm run build` | Компиляция TypeScript в `dist/`                                 |
| `npm run lint`  | Проверка ESLint                                                 |

## Подключение реальных платформ

1. Запустите webhook-режим: `npm start` (порт можно переопределить переменной `PORT`).
2. Передайте токены через переменные окружения — фреймворк подхватит их автоматически:

    | Платформа   | Переменная                                           |
    | ----------- | ---------------------------------------------------- |
    | Telegram    | `TELEGRAM_TOKEN`                                     |
    | Алиса       | `ALISA_TOKEN` (или `YANDEX_TOKEN`)                   |
    | VK          | `VK_TOKEN`, `VK_CONFIRMATION_TOKEN`, `VK_SECRET_KEY` |
    | Viber       | `VIBER_TOKEN`                                        |
    | MAX         | `MAX_TOKEN`                                          |
    | Маруся      | `MARUSIA_TOKEN`                                      |
    | SmartApp    | `SMARTAPP_TOKEN`                                     |
    | TTS в чатах | `SPEECH_KIT_TOKEN`                                   |

    Пример: `TELEGRAM_TOKEN=*** npm start`.

3. Укажите платформе публичный URL вебхука (например, через туннель), который ведёт на `localhost:3000`.

Токены не храните в коде и конфиге — только в переменных окружения (файл `.env` в `.gitignore`).
